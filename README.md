# 2027년 관광산업연구실 연구과제 발굴

별도 패키지 설치 없이 실행하는 정적 웹사이트 시안입니다.

## 실행

이 저장소에서 `python3 -m http.server 8000 --bind 0.0.0.0` 실행.

- index.html: 메인
- research.html: 경제·인문사회연구회 및 소관 연구기관 연구과제
- bids.html: 문화체육관광부 / 학술.연구용역(1169) 입찰공고

2022~2026년을 조회 범위로 사용합니다. 2026년은 조회 시점까지입니다.
모든 목록은 명시적으로 표시한 예시 자료이며 실제 검색 결과가 아닙니다.
