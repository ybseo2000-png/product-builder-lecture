# 2027년 관광산업연구실 연구과제 발굴

별도 패키지 설치 없이 실행하는 정적 웹사이트 시안입니다.

## 실행

이 저장소에서 `python3 -m http.server 8000 --bind 0.0.0.0` 실행.

- index.html: 메인
- research.html: 경제·인문사회연구회 및 소관 연구기관 연구과제
- bids.html: 문화체육관광부 / 학술.연구용역(1169) 입찰공고

2022~2026년을 조회 범위로 사용합니다. 2026년은 조회 시점까지입니다.
현재 목록은 공식 데이터 연계 대기 상태입니다. 실제 수집 전이므로 0건이라는 조회 결과를 주장하지 않습니다.

실제 연계 절차는 [API 설정 안내](docs/API_SETUP.md)를 확인하세요.

검증: `node scripts/validate-data.cjs`, `node --test tests/data.test.cjs`.

## 다음 단계

1. 공식 연구정보 제공처의 소관기관 범위, 날짜 기준, API/다운로드 제공 여부와 이용 조건 확인.
2. 공공데이터포털 조달청 입찰공고 API의 과거 조회 범위와 공고기관·업종 필드 확인.
3. 필요한 API 활용 신청 및 서버 환경에 인증키 보관 (브라우저 코드나 Git에 포함 금지).
4. 서버 수집 및 저장 계층 구현, 원문 링크·중복·변경·취소 처리 기준 확정.
5. 공식 원문과 대조 검증 후 실제 데이터 연계 및 배포.

## NKIS부터 연결하기

[NKIS 설정 안내](docs/NKIS_SETUP.md)에 따라 NKIS_API_KEY Secret을 등록한 후 수동 workflow를 실행합니다. 실제 키로 검증하기 전이며, 연구과제 전체가 아닌 발행연도 기준 연구보고서 API입니다.

## 주제어 네트워크

`network.html`에서 2022~2026년 또는 통합 기간의 주제어 관계와 관련 보고서를 확인합니다. [수집·분석 안내](docs/KEYWORDS.md)를 참고하세요. `Collect NKIS keywords` Actions가 체크포인트를 저장하면서 전체 목록의 주제어를 수집하고 Pages에 반영합니다. 매일 예약 실행으로 미처리 자료를 이어서 수집합니다.

## 문화체육관광부 정책연구 과제 (PRISM)

`prism.html`에서 기관코드 1371000, API 조회 기간 20220101~20270101의 과제와 보고서 원본 링크를 확인합니다. [요청·수집·배포 안내](docs/PRISM.md)를 참고하세요. GitHub Actions Secret `PRISM_API_KEY`를 사용하며 브라우저에는 키를 전달하지 않습니다.

## 나라장터 파일 목록

`bids.html`에서 사용자 제공 엑셀의 234건을 검색합니다. [파일 변환·갱신 방법](docs/NARA_IMPORT.md)을 참고하세요. 원문 URL과 업종코드가 없는 자료이므로 번호 검색을 제공하고 해당 한계를 표시합니다.
