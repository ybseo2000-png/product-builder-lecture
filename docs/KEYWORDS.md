# NKIS 주제어 수집

## 확인한 HTML 구조

사용자가 제공한 실제 HTML에 다음과 같이 보고서 주제어가 있습니다.

```html
<li><em>주제어</em><span>제조업, 경기, 지역, 현황, 전망</span></li>
```

`meta name="keywords"`는 사이트 공통 검색용 메타데이터라 분석에서 제외합니다. 주제어 목록에서 쉼표/세미콜론/줄바꿈을 구분자로 사용합니다. 공백과 유니코드 표기를 정리하고 보고서 안에서 같은 주제어는 한 번만 계산합니다. 동의어나 띄어쓰기 차이를 임의로 합치지는 않습니다.

## 코드 실행

```sh
# 받은 HTML만 오프라인 검사 (네트워크 요청 없음)
python3 scripts/collect_keywords.py --html /path/to/report.html

# 기본은 20건 이하, 요청 간격 1.5초의 소량 수집
python3 scripts/collect_keywords.py --limit 20 --delay 1.5

# 테스트
python3 -m unittest discover -s tests -p 'test_*.py'
```

별도 API 키나 브라우저 자동화는 필요 없습니다. 단, 공개 상세 페이지에 실제 주제어가 존재해야 합니다. 최소 요청 간격은 1초입니다. HTML 원문이나 쿠키는 저장하지 않습니다.

## 저장과 재개

`data/keywords.json`에 보고서 ID별 주제어, 발행연도, 제목, 공개 상세 링크, 조회 시각과 상태를 저장합니다. 한 보고서 처리 후마다 파일을 원자적으로 저장합니다.

- ok: 주제어 확보. 다음 실행에서 같은 링크면 재요청하지 않음.
- empty: 주제어 항목은 있으나 비어 있음. 다음 실행에서 재요청하지 않음.
- missing: 항목을 찾지 못함. 오류/로그인 페이지나 구조 변경일 수도 있으므로 주제어 없음으로 확정하지 않음. 재시도 대상.
- failed: 접속/디코딩 등 실패. 재시도 대상.

실제 누락 가능한 원본 보고서 목록을 바탕으로 하므로, 모든 연구과제의 분석이라고 주장하지 않습니다. 추후 네트워크 분석에서 연도별 전체 대상 수, 주제어 확보 수, 미수집/실패 수를 별도 표시해야 합니다.

## 범위와 남은 작업

처음에는 추출기와 소량 수집을 검증했고, 이후 자동 수집 workflow 및 네트워크 화면을 추가했습니다. 아래 전체 수집 및 배포 절차를 참고하세요. 제공기관의 이용·재이용 조건 및 요청 허용 범위를 준수해야 합니다. robots.txt 요청은 이 환경에서 HTML 오류 페이지를 반환했으므로 크롤링 허용의 근거로 사용하지 않습니다.

## 전체 수집 및 배포 (구현 완료, 실행 상태는 Actions에서 확인)

`Collect NKIS keywords` workflow는 수집 스크립트/워크플로 수정 push 시 자동 실행됩니다. Actions의 Run workflow로도 실행할 수 있습니다. 매일 02:15 한국시간(17:15 UTC)에 예약 실행되며 실제 시작 시각은 GitHub 대기열에 따라 달라집니다. 최대 5,000개 미처리 보고서에 요청하고, API 키는 사용하지 않습니다. 먼저 20개 실자료에서 추출을 검증했습니다.

160분 수집 단계 제한에 걸리면 저장된 체크포인트를 커밋하고 공개 페이지에 반영합니다. 다음 실행은 성공/주제어 빈 항목을 제외하고 미처리/실패/구조 미확인 항목을 이어서 처리합니다. 첫 전체 실행이 한 번에 끝나지 않더라도 확보율을 화면에 표시합니다. 테스트/저장/권한 오류가 있으면 별도 조치가 필요할 수 있으며 자동 수집 성공을 미리 보장하지 않습니다.

보고서 목록 수집 workflow와 주제어 workflow는 `nkis-data-maintenance` 동시 실행 그룹을 공유합니다. 오래된 보고서 목록으로 덮어쓰지 않도록 순차 실행합니다. Pages 배포는 공통 `Publish website` 재사용 workflow를 통해 수행합니다. 소스, 인증 설정 파일, 테스트는 배포 폴더에 넣지 않습니다.

## 주제어 네트워크 사용

`network.html`에서 발행연도 2022/2023/2024/2025/2026 또는 통합을 선택합니다. 2026년은 현재 등록된 보고서 기준입니다. 보고서 하나에서 주제어 쌍은 한 번만 계산합니다. 점 크기는 등장 보고서 수, 선 굵기는 함께 등장한 보고서 수입니다. 인과관계를 뜻하지 않습니다.

상위 30/50/100개 주제어 및 최소 공동 등장 보고서 수를 조절하고, 검색으로 표시 중인 주제어를 찾을 수 있습니다. 점 또는 주제어 버튼을 선택하면 관련 보고서와 연결된 주제어를 표시합니다. 확대/축소/맞춤 기능과 키보드 선택을 제공합니다. 주제어 확보율, 주제어 없음/미확인/실패/미수집 수를 기간별로 별도 표시합니다. 주제어 미확보 보고서는 관계 계산에서 제외합니다. 현재 단순 공백/유니코드 정리 외 동의어 병합은 하지 않습니다.

검증: 실제 20개 보고서에서 주제어 추출 성공. Python 테스트 17개, JavaScript 테스트 6개를 통과했으며 Chromium에서 실제 데이터 렌더링과 연도별 인공 fixture의 필터/연결 강도/빈 결과 동작을 확인했습니다. 전체 수집 완료 여부는 공개 화면의 집계와 Actions 결과를 확인해야 합니다.
